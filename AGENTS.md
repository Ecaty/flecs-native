Use Flecs C++17 for shared components/systems; keep the pinned upstream C sources unmodified and paired; record their commit and hashes in vendor/UPSTREAM.json. Preserve the `fu_*` C ABI and owned UTF-8 string contract. Core has no Unity dependency. Product-specific behavior belongs in the application module. World/query/Script operations run on the owning thread; REST edits are dequeued outside pipeline progress. Keep addon import order and repeated-world lifetime tests. Do not add a second simulation runtime or implement Jolt implicitly. Never store credentials in an ECS world or repository. Run the relevant root verification scripts after boundary changes.
